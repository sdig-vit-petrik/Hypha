# hypha 0.3.0

A new release line. The C++ SDK refuses invalid data where it enters instead of passing
on a value that looks valid, replay has two modes (the lockstep and an open loop), a
`WaitSet` and a session defend themselves against the two threading and lifetime
mistakes they used to leave undetected, message headers sit at their ROS 1 path, and
the tools and the C++ namespace have a short name, `hy`. `abi.revision` goes from 1
to 6. The wire frame format is unchanged.

## Breaking changes and upgrade

- **Upgrade.** Rebuild every process of a domain against 0.3.0 and follow
  [release-policy.md](../release-policy.md) §5: stop the domain, install, reset its
  shared memory, start. The library file name changes with `abi.revision`. A rollback
  to 0.2.0 is the same procedure with the 0.2.0 build.
- **Message include paths.** Message headers are generated and installed at
  `<package>/<Name>.h`; the `hypha_msgs/` prefix is gone, with no forwarding header
  (#120). Drop `hypha_msgs/` from each message include line:
  `<hypha_msgs/sensor_msgs/Imu.h>` becomes `<sensor_msgs/Imu.h>`, and
  `<hypha_msgs/hypha_msgs/NodeState.h>` becomes `<hypha_msgs/NodeState.h>`. Remove any
  include directory added to reach the unprefixed paths. `hypha_msgs/ros_time.h` stays.
  hypha-cxx owns the directory of each standard package; an application owns the
  directories of the packages it declares. A process cannot use hypha messages together
  with a ROS installation's message headers.
- **Non-finite seconds.** `Duration::fromSeconds`, `Time::fromSeconds` and
  `Duration * double` throw `std::invalid_argument` for NaN or infinity; they returned
  zero (#126). In a constant expression such input no longer compiles.
  `Duration::tryFromSeconds` is the form that does not throw.
- **Transforms.** A lookup has a new answer, `TransformError::Refused`
  (`HYPHA_TF_REFUSED`), so a `switch` over the enum needs a case.
  `StaticTransformBroadcaster::send()` refuses an invalid transform; it used to send
  and keep it (#123).
- **Parameter files.** The top-level key `unused` is reserved: it lists keys that are
  set on purpose and not read (#119). A file that used `unused` as a parameter must
  rename it.
- **Node manifest.** `hypha_msgs/IntrospectedConfig` gains `SOURCE_IGNORED`, which
  changes the schema hash of `NodeIntrospection`: a 0.2.0 tool does not read the
  `~/introspection` of a 0.3.0 node, and the reverse.
- **Message definitions.** A field or constant name must match
  `[A-Za-z][A-Za-z0-9_]*`, and text after a field name is refused (#124). A definition
  with a ROS 2 default value (`float64 x 1.0`) no longer generates; drop the value.
- **Simulated time going back.** A `/clock` sample below the node's last one ends the
  run of any `WaitSet` on simulated time with `ClockRewound`, also one that holds only
  subscriptions (#130). A command-line tool's node is exempt.
- **Two threads on one `WaitSet`.** A call or a run that a second thread starts while
  one is inside a call on the `WaitSet` returns `InvalidState` (#83). Two threads that
  both configured one `WaitSet` between runs, a silent race before, now see the refusal.
- **Tool names.** The linked names of the tools are `hy<tool>` (`hytopic`, `hyplay`,
  ...); the `hypha_<tool>` links are gone, with no compatibility links, and the CMake
  target `hypha::foxglove_bridge` is `hypha::foxglove` (#164). `hypha <tool>` is
  unchanged.
- **Cleaning shared memory.** `clean-shm.sh --domain` is gone; `hypha clean --domain
  <prefix>` takes its place (#163). `clean-shm.sh` keeps the wipe of every domain of
  the host.
- **Several `Node`s in one process.** The session is left by the last `Node` destroyed,
  not by the first one made. A publisher whose node has left refuses `publish()` with
  `InvalidState`; it used to report a send (#97).

## Changes

- **Open-loop playback.** `HYPHA_REPLAY_LOCKSTEP=0`, set once for a whole launch, turns
  the replay lockstep off: `hypha play --clock` sends `/clock` and the data on the
  `--rate` schedule and waits for no node, as a ROS playback does; a lost replay input
  is counted and warned of. The lockstep stays the default (#102, #147). Replay has
  these two modes and no other.
- **The lockstep is for cycles.** Its contract is rate and triggered cycle nodes. A
  plain callback on a node in the lockstep runs as its sample or timer arrives and is
  neither held nor waited for, as in 0.2.0 (#153).
- **The lockstep says what it waits for.** After 1 s of waiting `hypha play` names the
  nodes it waits for. A node whose reported clock does not rise for `--timeout` ends
  the replay, whether it went quiet or keeps reporting; the error names each node,
  says when the nodes hold for each other, and points to the open loop (#148).
- **Invalid transforms are refused at the sender.** `hypha::TransformBroadcaster` for
  `/tf`, beside the static one: `send()` applies the check every buffer applies on
  ingest (`hypha_transform_check`) and refuses with the reason and both frames. A
  lookup through a frame whose newest transform was refused answers `Refused`, not
  "unknown" or "not yet". New node metrics: `tf.refused`, `tf.undecodable` (#123).
- **Parameters set on purpose but not read.** A file lists them in `unused`; code marks
  them with `ConfigView::ignore(key_or_prefix, reason)` (`hypha_config_ignore`). Such a
  key leaves the unread-key check and is a manifest row with its reason; an entry the
  file does not set, and a typo beside it, are still refused (#119).
- **Timers a callback can control.** A plain timer can be canceled, reset and read,
  also from a callback of the running `WaitSet`, and a callback may create one on host
  time or on the node's own simulated clock (`hypha_waitset_timer_cancel`, `_reset`,
  `_state`) (#90).
- **Names for the C++ result enums.** `hypha::name()` for `TransformError`,
  `InputVerdict` and `StopReason` (#100).
- **`hypha convert`.** Turns a ROS 2 bag in rosbag2's SQLite storage into a recording
  that `hypha play` replays; no ROS is needed (#46).
- **`hypha clean`.** Removes the shared memory of the current domain, or with
  `--domain <prefix>` of the domains under a prefix. A domain is kept while one of its
  nodes is alive or its test run still lives; the tool kills nothing and says what it
  removed and kept. It is installed with the SDK (#163).
- **Tests in their own bus domains.** The SDK installs `hypha_add_test()`, which
  registers a CTest test in a domain of its own under the test root `t_`; `hypha clean
  --domain t_` removes the domains of the runs that ended. `./test.sh` no longer clears
  every domain of the host, so it runs beside a running system (#127).
- **Short names.** `hy` is a second name of the `hypha` executable, and `hy<tool>`
  starts a tool directly (#164). In C++, `hy` is a namespace alias of `hypha`
  (`hy::Node`); a translation unit with a global `hy` of its own defines
  `HYPHA_NO_SHORT_NAMESPACE` before its first hypha include (#167).
- **ROS 2 style message headers.** `hypha_generate_ros2_headers()` generates
  `<pkg>/msg/<name>.hpp` alias headers with `pkg::msg::Name` for an application's own
  packages and the standard ones; hypha installs none. The types stay the ROS 1 ones
  (#57).
- **Documents.** A transform lookup never waits (#91). The migration guide sends an
  event-driven node with one working input to a triggered cycle (#138). A design note
  records why cycles and plain callbacks keep two step shapes
  ([execution-model.md](../execution-model.md) §11.3, #136).
- **Dependencies.** `url` 2.5.9 (RUSTSEC-2026-0592, #89). The workspace builds without
  warnings on the current stable Rust (#116).

## Assumptions of use

AoU-22, the one-thread rule of a `WaitSet`, is now enforced: a breach is refused with
`InvalidState`, and FM-37 is a detected fault ([failure-analysis.md](../failure-analysis.md),
[safety-manual.md](../safety-manual.md)). An application treats that status as a fault
of its own threading. No other assumption of use changed.
