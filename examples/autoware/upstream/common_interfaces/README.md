# common_interfaces sensor_msgs and std_srvs (vendored)

From https://github.com/ros2/common_interfaces, branch `jazzy`, commit
`a941f14bb318d8d904505ed935ccbb97f24a70a4` (a941f14):

- `sensor_msgs/include/sensor_msgs/point_cloud2_iterator.hpp` and its
  `impl/point_cloud2_iterator.hpp`, the header-only `PointCloud2` iterators and modifier;
- `std_srvs/srv/SetBool.srv`, the EKF's `trigger_node` service.

Licence: `LICENSE` in this directory (Apache 2.0, from `sensor_msgs/LICENSE`; `std_srvs`
carries the same file).

The files are unchanged. The iterators run on hypha's `sensor_msgs::PointCloud2`, which the
shim names `sensor_msgs::msg::PointCloud2` (`../../shim/include/sensor_msgs/msg/`);
`SetBool.srv` is generated by `hypha_generate_messages`, and the shim names it
`std_srvs::srv::SetBool` (`../../shim/include/std_srvs/srv/`).
